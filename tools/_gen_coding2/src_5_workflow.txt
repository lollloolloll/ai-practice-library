# SPEC.md — 할 일 목록 앱

## 1. 목표
- 개인이 하루 할 일을 **5초 안에** 적고 지울 수 있는 가벼운 웹앱
- 설치·로그인 없이 브라우저에서 바로 사용, 새로고침해도 내용 유지

## 2. 사용자 스토리
| ID | 사용자로서 | ~하고 싶다 | 그래서 |
|---|---|---|---|
| US-1 | 사용자 | 할 일을 입력하고 Enter로 추가 | 생각나는 즉시 적을 수 있다 |
| US-2 | 사용자 | 체크해서 완료 표시 | 진행 상황을 본다 |
| US-3 | 사용자 | 항목을 삭제 | 목록을 깔끔하게 유지한다 |
| US-4 | 사용자 | 전체/진행 중/완료 필터 | 남은 일에 집중한다 |
| US-5 | 사용자 | 브라우저를 닫았다 열어도 유지 | 다시 입력하지 않는다 |

## 3. 범위 밖 (이번 버전에서 하지 않음)
- 로그인·여러 기기 동기화 · 마감일/알림 · 드래그 정렬 · 하위 할 일 · 다크 모드

## 4. 데이터 모델
```ts
type Todo = {
  id: string;        // crypto.randomUUID()
  text: string;      // 1~100자, 앞뒤 공백 제거
  done: boolean;
  createdAt: number; // Date.now()
};
// localStorage key: "todos.v1" → Todo[] (JSON)
```

## 5. 화면 구성
입력창 + 추가 버튼 → 필터 탭(전체/진행 중/완료) → 목록 → 하단 "남은 할 일 N개 · 완료 항목 지우기"

## 6. 완료 조건 (Acceptance Criteria)
- [ ] AC-1 공백만 입력하면 추가되지 않는다
- [ ] AC-2 100자를 넘으면 오류 문구가 보인다
- [ ] AC-3 새로고침 후에도 목록과 완료 상태가 유지된다
- [ ] AC-4 375px 폭에서 가로 스크롤이 생기지 않는다
- [ ] AC-5 키보드만으로 추가·완료·삭제가 가능하다
- [ ] AC-6 `<script>` 같은 입력이 실행되지 않고 글자로 보인다
- [ ] AC-7 콘솔 오류 0개

## 7. 기술 결정
- 단일 HTML 파일, 바닐라 JS (의존성 0개)
- 열린 질문: 필터 상태도 새로고침 후 유지할까요? (기본안: 유지하지 않음)

@@file src/lib/todos.js
export const addTodo = (todos, text) => {
  const trimmed = text.trim();
  return trimmed ? [...todos, { id: crypto.randomUUID(), text: trimmed, done: false }] : todos;
};

export const toggleTodo = (todos, id) => todos.map((t) => (t.id === id ? { ...t, done: !t.done } : t));

export const removeTodo = (todos, id) => todos.filter((t) => t.id !== id);

@@file src/main.js
import { addTodo, removeTodo, toggleTodo } from './lib/todos.js';

const form = document.getElementById('form');
const list = document.getElementById('list');
let todos = JSON.parse(localStorage.getItem('todos') ?? '[]');

const update = (next) => {
  todos = next;
  localStorage.setItem('todos', JSON.stringify(todos));
  render();
};

function render() {
  list.replaceChildren(...todos.map((todo) => {
    const li = document.createElement('li');
    const box = Object.assign(document.createElement('input'), { type: 'checkbox', checked: todo.done });
    box.addEventListener('change', () => update(toggleTodo(todos, todo.id)));
    const span = document.createElement('span');
    span.textContent = todo.text;
    const del = document.createElement('button');
    del.textContent = '삭제';
    del.addEventListener('click', () => update(removeTodo(todos, todo.id)));
    li.append(box, span, del);
    return li;
  }));
}

form.addEventListener('submit', (e) => {
  e.preventDefault();
  update(addTodo(todos, form.text.value));
  form.reset();
});

render();

<script>
  let todos = JSON.parse(localStorage.getItem('todos')) || [];

  function save() {
    localStorage.setItem('todos', JSON.stringify(todos));
  }

  function render() {
    const list = document.getElementById('todoList');
    list.innerHTML = '';
    todos.forEach((todo, index) => {
      const li = document.createElement('li');
      if (todo.done) li.classList.add('done');
      li.innerHTML = `<input type="checkbox" ${todo.done ? 'checked' : ''}><span>${todo.text}</span><button class="edit">수정</button><button class="delete">삭제</button>`;
      li.querySelector('input').onchange = () => { todos[index].done = !todos[index].done; save(); render(); };
      li.querySelector('.edit').onclick = () => { const text = prompt('할 일 수정', todos[index].text); if (text) { todos[index].text = text; save(); render(); } };
      li.querySelector('.delete').onclick = () => { todos.splice(index, 1); save(); render(); };
      list.appendChild(li);
    });
  }

  function addTodo() {
    const input = document.getElementById('todoInput');
    const text = input.value;
    if (text) {
      todos.push({ text: text, done: false });
      input.value = '';
      save();
      render();
    }
  }

  document.getElementById('addBtn').onclick = addTodo;
  document.getElementById('todoInput').addEventListener('keypress', (e) => {
    if (e.key === 'Enter') addTodo();
  });

  render();
</script>
