## 할 일

1. **장면 흐름(스토리보드) 정리**: 대상마다 실사용 캡처를 순서대로 고르고 장면 번호, 제목, 한 줄 설명을 붙여 `ui/storyboard.json`에 기록해요.
   - 크랙: 로그아웃 홈 → 취향 선택 → 작품 상세 → 대화방(로그아웃) → 첫 메시지에서 뜨는 로그인 벽(`s01-room-open` 다음 장면은 `ui/raw` 쪽 로그인 창 캡처가 없다면 `research`로 설명) → 로그인 후 대화방 → 첫 응답(상태창·뉴스·선택지) → 추천답변 3개 → 직접 입력 → 두 번째 응답 → "최대 출력량 조절" 결제 유도 창(`s06`/`s07` 확인) → 마이페이지 크래커 잔액 → 비주얼 노벨.
   - Habitica: Yesterdailies 창 → 소식 창(라이브 운영) → 할 일 보드 → 습관 + → 레벨업 창 → 일일 체크 → 할 일 완료 → 플레이 뒤 보드 → 편집 창 → 인벤토리 → 마구간 → 상점 → 파티 → 챌린지 → 능력치·업적 → 모바일.
2. **표시본(annotated) 만들기**: PIL로 원본 위에 번호 동그라미와 테두리 상자를 그려 `ui/annotated/<같은 이름>.jpg`로 저장해요. 원본은 그대로 둬요. 표시 좌표와 설명은 `storyboard.json`에 함께 기록해요(이미지 좌표 px). 표시할 것 예: 크랙의 상태창, [속보] 뉴스, 추천답변, 크래커 잔액, 출력량 결제 창 / Habitica의 경험치·골드 알림, 레벨업, 할 일 색 막대, 체력·경험치 막대.
3. **페이지를 이미지 중심으로 다시 만들기**: `cases/crack.html`, `cases/habitica.html` 맨 위에 "실제로 써 보면" 스토리보드를 둬요. 큰 이미지 한 장씩, 번호 설명이 옆이나 아래에 붙고, 좌우로 넘겨요(키보드·스와이프). 기존 분석 섹션은 그 아래로 내려요. 홈 화면과 비슷한 기존 로그아웃 캡처는 보조 갤러리로 줄여요.
4. **AI용 파일 갱신**: 각 `README.md`에 `ui/session/`, `ui/annotated/`, `ui/storyboard.json`을 추가하고, 실사용에서 새로 확인한 사실(예: 크랙 무료 대화권으로 크래커가 줄지 않음, 출력량 조절 결제 창, AI가 계정 이름을 주인공 이름으로 씀 / Habitica의 Yesterdailies, 레벨업 창, 소식 창)을 `synthesis.json` 또는 findings에 근거 이미지와 함께 넣어요(status: observed).
5. **검증**: 로컬 서버(`python -m http.server 8765`)로 두 페이지를 열어 데스크톱 1280px와 모바일 375px에서 이미지가 뜨는지, 가로 스크롤이 없는지, 콘솔 오류가 없는지 확인해요. 실명이 화면이나 텍스트 파일에 없는지 `grep -r "조강현"`으로 확인해요(결과 0이어야 해요).
