# 마감(폴리싱) 기록 — Prompt Lexicon 자체를 사례로

상용 서비스처럼 보이게 만드는 디테일을 하나씩 고치며 전/후를 남겨요. 나중에 "마감" 분야 용어와 이 프로젝트 실전 사례의 근거가 돼요.

점검 방법: 2026-11-05, 로컬(`python -m http.server 8765`)과 GitHub Pages에서 내장 브라우저로 직접 써 보며 DOM·성능 API로 측정했어요. 전체 후보 목록은 20개예요(아래 "남은 것").
